Допомога

Як використовувати систему

Ця система допомагає нормалізувати українські адреси та знаходити підсудні районні суди.

1. Одиночна адреса

Введіть адресу в довільному форматі, система автоматично:

  • Розпізнає компоненти адреси
  • Нормалізує відповідно до стандартів Укрпошти
  • Знайде підсудний районний суд

2. Пакетна обробка

Завантажте CSV або Excel файл з адресами. Формати файлів:

Формат 1: Повна адреса в одному полі

address
"01001, Київська область, м. Київ, Печерський район, вул. Хрещатик, 1"
"79000, Львівська область, м. Львів, вул. Винниченка, 24"

Формат 2: Окремі поля

oblast,district,city,street,house,apartment,postal_code
"Київська область","Шевченківський район","м. Київ","вул. Дегтярівська","31-А",,01032

3. Експорт результатів

Після обробки ви можете експортувати результати у:

  • CSV формат - для подальшої обробки
  • Excel (XLSX) - з форматуванням та кольоровим кодуванням

4. База судів

Перегляньте повну базу районних судів України з можливістю пошуку за назвою або областю.

API

Система також надає API endpoints:

  • POST /api/normalize - нормалізація адреси
  • POST /api/find_court - пошук суду за адресою

Технічні вимоги

  • Максимальний розмір файлу: 16 МБ
  • Підтримувані формати: CSV, XLSX, XLS
  • Кодування CSV: UTF-8 (рекомендовано)
