# База даних адрес України для пошуку судової підсудності

Система для визначення підсудності місцевих судів першої інстанції загальної юрисдикції за адресою в Україні.

## Опис

Цей проект містить:
- **База даних SQLite** з адресами України (області, райони, населені пункти)
- **Інформація про суди** (місцеві суди першої інстанції)
- **Mapping юрисдикцій** - зв'язок між територіями та судами
- **Web-інтерфейс** для пошуку підсудності
- **API для пакетної обробки** адрес з CSV файлів

## Встановлення та запуск

### 1. Встановіть залежності

```bash
pip install -r requirements.txt
```

### 2. Імпортуйте дані в базу


Скрипт створить базу даних `database/ukraine_addresses.db` та імпортує всі дані з CSV файлів.

- Області: 26
- Райони: 120+
- Населені пункти: 68+ (основні міста)

```bash
python scripts/webapp.py
```

## Використання

### Веб-інтерфейс

1. **Пошук підсудності** - головна сторінка
   - Введіть область, район та/або населений пункт
   - Натисніть "Знайти суд"
   - Отримайте детальну інформацію про суд з юрисдикцією

2. **Пакетна обробка** (`/batch`)
   - Завантажте CSV файл з колонками: `oblast`, `district`, `settlement`
   - Система автоматично знайде підсудність для кожної адреси
   - Результат відобразиться в таблиці

3. **Нормалізація адрес** (`/normalize`)
   - Завантажте CSV файл з адресами
   - Система нормалізує регістр та форматування
   - Завантажте оброблений файл

### Приклад CSV файлу для пакетної обробки

```csv

Львівська область,Львівський район,Львів
```

### Програмний доступ (Python API)

```python
from scripts.database import find_court_by_jurisdiction

# Знайти суд за адресою
court = find_court_by_jurisdiction(
    oblast_name="Київська область",
    raion_name="Броварський район",
```

## Схема бази даних

### Таблиці

1. **oblasts** - Області України
   - `id` - унікальний ідентифікатор
   - `name` - назва області
   - `name_en` - назва англійською
   - `koatuu_code` - код КОАТУУ

2. **raions** - Райони
   - `id` - унікальний ідентифікатор
   - `name` - назва району
   - `oblast_id` - посилання на область
   - `koatuu_code` - код КОАТУУ

3. **settlements** - Населені пункти
   - `id` - унікальний ідентифікатор
   - `name` - назва населеного пункту
   - `type` - тип (місто, селище, село)
   - `oblast_id` - посилання на область
   - `raion_id` - посилання на район
   - `koatuu_code` - код КОАТУУ
   - `population` - населення

4. **courts** - Місцеві суди
   - `id` - унікальний ідентифікатор
   - `name` - скорочена назва
   - `full_name` - повна офіційна назва
   - `type` - тип (районний, міський, міськрайонний, окружний)
   - `address` - адреса суду
   - `phone` - телефон
   - `email` - електронна пошта
   - `website` - веб-сайт

5. **jurisdiction** - Юрисдикція (mapping)
   - `id` - унікальний ідентифікатор
   - `court_id` - посилання на суд
   - `oblast_id` - посилання на область (опціонально)
   - `raion_id` - посилання на район (опціонально)
   - `settlement_id` - посилання на населений пункт (опціонально)
   - `notes` - примітки

### Представлення (Views)

**address_jurisdiction** - зручне представлення для пошуку підсудності з об'єднанням всіх таблиць

## Алгоритм пошуку підсудності

Система використовує ієрархічний підхід до визначення підсудності:

1. **Пріоритет 1**: Пошук по населеному пункту
   - Якщо вказано конкретне місто/село, шукається суд з юрисдикцією саме для цього населеного пункту

2. **Пріоритет 2**: Пошук по району
   - Якщо точний населений пункт не знайдено, шукається суд з юрисдикцією для всього району

3. **Пріоритет 3**: Пошук по області
   - Якщо не знайдено на рівні району, шукається суд з юрисдикцією для області

Це забезпечує максимально точне визначення підсудності навіть при неповних даних.

## Додавання нових даних

### Додати нову область

Відредагуйте `data/oblasts.csv`:
```csv
Нова область,New Oblast,0000000000
```

### Додати новий суд

Відредагуйте `data/courts.csv`:
```csv
Новий суд,Повна назва Нового суду,районний,адреса,телефон,email,website,
```

### Додати юрисдикцію

Відредагуйте `data/jurisdiction.csv`:
```csv
Новий суд,Область,Район,Населений пункт,Примітки
```

Після редагування CSV файлів запустіть:
```bash
python scripts/import_data.py
```

## Розширення можливостей

### Міграція на PostgreSQL

Для продакшн використання рекомендується PostgreSQL:

1. Встановіть psycopg2: `pip install psycopg2-binary`
2. Змініть `database.py` для підключення до PostgreSQL
3. Адаптуйте `schema.sql` під PostgreSQL синтаксис

### REST API

Можна додати REST API endpoints:

```python
@app.route('/api/court', methods=['GET'])
def api_find_court():
    oblast = request.args.get('oblast')
    raion = request.args.get('raion')
    settlement = request.args.get('settlement')

    court = find_court_by_jurisdiction(oblast, raion, settlement)
    return jsonify(court) if court else jsonify({'error': 'Not found'}), 404
```
