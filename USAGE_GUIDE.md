## 🖥️ Як користуватися

### Веб-інтерфейс

1. **Головна сторінка** - пошук одного суду:
   - Введіть область (наприклад: "Київська область")
   - Введіть район (наприклад: "Броварський район")
   - Введіть місто (наприклад: "Бровари")
   - Натисніть "Знайти суд"

2. **Пакетна обробка** (`/batch`):
   - Завантажте CSV файл з колонками: `oblast,district,settlement`
   - Приклад є в `examples/sample_addresses.csv`
   - Результат покаже суд для кожної адреси

3. **Нормалізація** (`/normalize`):
   - Завантажте CSV файл
   - Система виправить регістр та форматування

### Python API

```python
from scripts.database import find_court_by_jurisdiction

# Пошук суду
court = find_court_by_jurisdiction(
    oblast_name="Львівська область",
    raion_name="Львівський район",
    settlement_name="Львів"
)

if court:
    print(f"Суд: {court['name']}")
    print(f"Адреса: {court['address']}")
    print(f"Телефон: {court['phone']}")
    print(f"Email: {court['email']}")
    print(f"Веб-сайт: {court['website']}")
```

## ❌ ЩО НЕ ВКЛЮЧЕНО (поточна версія)

### 1. ❌ Вулиці та номери будинків
**Причина:** База зосереджена на рівні міста/району для визначення суду
**Вплив:** Пошук працює на рівні населеного пункту

### 2. ❌ Перейменовані міста
**Відсутні:**
- Кіровоград → Кропивницький ✗
- Дніпропетровськ → Дніпро ✗
- Артемівськ → Бахмут ✗
- Червоноармійськ → Покровськ ✗
- та інші декомунізовані назви

**Що є:** Тільки НОВІ назви (після 2016 року)

### 3. ❌ Райони міст (внутрішні)
**Відсутні:**
- Райони Києва (Печерський, Оболонський тощо) - є тільки суди
- Райони Харкова, Одеси, Львова тощо

### 4. ❌ Старі райони областей
**Відсутні:** Райони до реформи 2020 року
**Що є:** Тільки нові укрупнені райони

**Приклад:** До реформи у Київській області було ~25 районів, після - 7 районів

### 5. ❌ Перейменовані суди
**Приклад:**
- Артемівський міський суд → Бахмутський міський суд ✗
- Старі назви судів не збережені

### 6. ❌ Тимчасово переміщені суди
**Відсутня інформація про:**
- Суди з Донецької області (працюють у Маріуполі, Бахмуті)
- Суди з Луганської області (працюють у Старобільську, Сєвєродонецьку)
- Суди з Херсонської області
- Суди з окупованого Криму та Севастополя

**Важливо:** Це критична прогалина для реальних справ!

### 7. ❌ Села та невеликі селища
**Охоплення:** ~68 міст з 1,469+ населених пунктів в Україні
**Відсоток:** ~4.6% населених пунктів

## 🛠️ Як додати дані

### Додати тимчасово переміщені суди

1. Відредагуйте `data/courts.csv`:
```csv
Маріупольський міський суд (тимчасово переміщений),Маріупольський міський суд Донецької області,міський,"м. Дніпро, вул. Тимчасова, 1 (тимчасово)",+380563451234,inbox@mariupol.dn.court.gov.ua,mariupol.dn.court.gov.ua,
```

2. Додайте примітку в `data/jurisdiction.csv`:
```csv
Маріупольський міський суд (тимчасово переміщений),Дніпропетровська область,Дніпровський район,Дніпро,Тимчасово переміщений з м. Маріуполя у зв'язку з окупацією
```

3. Запустіть імпорт:
```bash
python scripts/import_data.py
```

### Додати альтернативні назви міст

**Варіант 1:** Додати колонку `old_names` в таблицю `settlements`:

```sql
ALTER TABLE settlements ADD COLUMN old_names TEXT;
```

**Варіант 2:** Створити окрему таблицю:

```sql
CREATE TABLE settlement_aliases (
    id INTEGER PRIMARY KEY,
    settlement_id INTEGER,
    alias_name TEXT,
    valid_from DATE,
    valid_to DATE,
    reason TEXT,
    FOREIGN KEY (settlement_id) REFERENCES settlements(id)
);
```

Потім додати:
```csv
settlement_id,alias_name,valid_from,valid_to,reason
25,Кіровоград,1939-01-01,2016-07-21,Декомунізація
25,Кропивницький,2016-07-21,,Новий офіційний назва
```

### Додати всі села

Завантажте офіційний класифікатор з сайту Держстату або ВРУ та імпортуйте.
